# REGN Lab

Fem iPhone-PWA-prototyper. Midtstil. Local-first.

Live: https://fotoblinkskudd2-create.github.io/regn-lab/ (krever at Axel slår på Pages — se PAGES-SETUP.md)

## Apper

| App | Problem | Kilde |
|---|---|---|
| PUST | Panikk i øyeblikket | [Lugn-Trygg](https://github.com/omar1u7777/Lugn-Trygg) |
| SKAP | Mat går ut | [Keep Fresh](https://github.com/touhidtamim/Keepfresh-Client-Side) |
| DOSE | Glemt dose | [Meditrax](https://github.com/dizzafizza/Meditrax) |
| SJEKK | Bor alene | [SafeCheck](https://github.com/alfredang/iamgood) |
| KONVOLUTT | Penger uten ramme | [Actual Budget](https://github.com/actualbudget/actual) |

## iPhone på 60 sekunder

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)` → Save
4. Vent ~30 sek
5. Åpne `https://fotoblinkskudd2-create.github.io/regn-lab/` i **Safari**
6. Del → **Legg til på Hjem-skjerm**

Ikke bruk Chrome på iPhone. PWA-install er Safari.
