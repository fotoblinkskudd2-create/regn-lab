# Slå på GitHub Pages — 3 klikk (Axel må gjøre dette, krever repo-admin)

1. Åpne <https://github.com/fotoblinkskudd2-create/regn-lab/settings/pages>
2. Under **Build and deployment → Source**: velg **Deploy from a branch**
3. Branch: **`main`** · Folder: **`/ (root)`** → **Save**

Vent ~30–60 sekunder. Åpne <https://fotoblinkskudd2-create.github.io/regn-lab/> i **Safari** på iPhone → **Del → Legg til på Hjem-skjerm**.

- `.nojekyll` ligger allerede i repo-roten — ingenting mer må til.
- Ikke bruk Chrome på iPhone; PWA-install går bare via Safari.
- Hvis siden svarer 404 etter 2 min: Actions-fanen viser `pages build and deployment`-jobben — se om den er grønn.
